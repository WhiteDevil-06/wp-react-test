# UI/UX Skill

## Palette & Style Guide
- Background: Deep Obsidian (`#06080d`, `#0b0f19`)
- Primary Glow / Accent: Cyan (`#06b6d4`), Electric Violet (`#8b5cf6`), Emerald (`#10b981`)
- Surface: Glassmorphic dark containers (`rgba(255,255,255,0.03)` with subtle borders `rgba(255,255,255,0.08)`).
- Typography: Clean sans-serif, high contrast headings, muted body text (`#94a3b8`).
- Whitespace: Generous editorial margins and section padding.
