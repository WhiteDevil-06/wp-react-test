# Mandatory SEO Verification Checklist

Before any page deployment is approved:

- [ ] Title tag present, unique, and < 60 chars.
- [ ] Meta description present, unique, and < 155 chars.
- [ ] Canonical URL tag present and pointing to canonical route.
- [ ] Single `<h1>` tag matching page intent.
- [ ] Heading hierarchy (`<h2>`, `<h3>`) correctly ordered without skips.
- [ ] Alt text present on all images.
- [ ] Open Graph (og:title, og:description, og:image, og:url) configured.
- [ ] JSON-LD Structured Data validated without warnings.
- [ ] Mobile viewport meta tag configured.
- [ ] Page included in dynamic `sitemap.xml`.
