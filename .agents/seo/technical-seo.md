# Technical SEO Guidelines

## Core Requirements
- **URL Structure**: Clean, lowercase, hyphen-separated routes (e.g., `/services/linkedin-personal-branding`).
- **Canonical Tags**: Self-referencing canonical tag on every page.
- **Sitemap**: Dynamic XML sitemap generator configured at `/sitemap.xml`.
- **Robots.txt**: Clean robots policy permitting indexing of public pages while guarding API routes.
- **Open Graph & Metadata**: Fully configured og:image, og:title, og:description, twitter:card, twitter:site on all pages.
- **Core Web Vitals**: Largest Contentful Paint (LCP) < 2.0s, First Input Delay (FID) < 100ms, Cumulative Layout Shift (CLS) < 0.05.
