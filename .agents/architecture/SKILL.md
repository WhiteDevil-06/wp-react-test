# Architecture Agent Skill

## Responsibilities
- Define system architecture, directory structures, technology choices, and performance budgets.
- Ensure strict separation of concerns between client components, server rendering, API endpoints, and data layers.
- Maintain Architecture Decision Records (ADRs) for major system choices.
- Guarantee maintainability, scalability, and technical debt prevention.
