# Accessibility Agent Skill

## Responsibilities
- Ensure every element and component satisfies WCAG 2.1 AA standards.
- Enforce semantic HTML elements (`<main>`, `<nav>`, `<header>`, `<footer>`, `<section>`, `<article>`).
- Verify keyboard focus management and screen reader accessible labeling (`aria-label`, `aria-describedby`, `aria-expanded`).
