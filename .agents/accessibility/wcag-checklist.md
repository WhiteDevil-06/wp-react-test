# WCAG 2.1 AA Checklist

- [ ] All interactive elements accessible via `Tab` keyboard navigation.
- [ ] Visual focus ring clearly visible on all focused controls.
- [ ] Color contrast >= 4.5:1 for body text, >= 3:1 for large text / graphical icons.
- [ ] All images have descriptive non-empty `alt` attributes (decorative images set to `alt=""`).
- [ ] All form inputs have explicit linked `<label>` or `aria-label`.
- [ ] Motion/animations respect `prefers-reduced-motion`.
- [ ] Interactive overlays lock focus traps and restore focus on close.
