# HYLOS SUB-AGENT SYSTEM (.agents)

This directory contains the specialized sub-agent guidelines, instructions, skill rules, and decision records for rebuilding the Hylos B2B Marketing & Growth digital experience.

## Sub-Agent Roster

1. **SEO Agent** (`.agents/seo/`): Keyword strategy, metadata, schemas, intent mapping, Core Web Vitals, and indexability.
2. **UI/UX Agent** (`.agents/ui-ux/`): Editorial layout, design tokens, responsiveness, WCAG compliance, interaction patterns.
3. **Branding Agent** (`.agents/branding/`): Brand positioning, visual language, messaging hierarchy, logo rules, brand voice.
4. **Frontend Agent** (`.agents/frontend/`): Next.js/React architecture, component modularity, performance, hydration efficiency.
5. **Backend Agent** (`.agents/backend/`): Enquiry API, validation, security, rate limiting, MongoDB integration.
6. **Content Agent** (`.agents/content/`): Copy writing, B2B intent alignment, factual integrity, lead capture framing.
7. **Accessibility Agent** (`.agents/accessibility/`): WCAG 2.1 AA compliance, keyboard focus, screen reader semantics.
8. **Testing Agent** (`.agents/testing/`): Unit, functional, responsive, SEO, and integration validation.
9. **Architecture Agent** (`.agents/architecture/`): System design governance, technical stack validation, Architecture Decision Records (ADRs).
