# UI/UX Design System Reference

- **Palette**: Surface (`#f5faff`), Container (`#e9eef3`), Primary Cyan (`#006689` / `#06b3ed`), Action Orange (`#EA6523`).
- **Typography**: Display XL (80px/88px), Headline Large (40px/48px), Body Large (18px/32px), Technical Labels (12px Mono).
- **Corner Radii**: Standard `4px` subtle architectural corners. No giant pill shapes for standard components.
- **Borders**: 1px structural borders using outline variant (`#bdc8d0` or `#3d484f`).
