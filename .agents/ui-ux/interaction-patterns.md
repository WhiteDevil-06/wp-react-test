# Interaction Patterns & Micro-Animations

- **Hover States**: Subtle shift in border brightness or subtle node connection highlight.
- **Orbital Graphics**: Slow rotational arcs (20s+ duration) and pulsing node indicators.
- **Buttons**: Micro scale-up (`scale(1.02)`) on hover; explicit active press state (`scale(0.98)`).
- **Page Transitions**: Smooth opacity fade-in for section reveals using Framer Motion.
