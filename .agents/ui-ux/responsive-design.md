# Responsive Design Guidelines

## Breakpoints
- **Mobile**: 320px – 767px (4-column fluid grid, 24px outer margin).
- **Tablet**: 768px – 1023px (8-column fluid grid, 32px outer margin).
- **Desktop**: 1024px – 1440px+ (12-column grid, max width 1440px, 64px outer margin).

## Rules
- Mobile layouts are not simplified desktop crops; touch targets must measure at least 44x44px.
- Typography scales fluidly using mobile display font specs (Display XL: 48px, Headline Large: 32px).
- Navigation switches gracefully to full-overlay editorial drawer on mobile devices.
