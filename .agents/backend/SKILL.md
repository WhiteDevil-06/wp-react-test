# Backend Agent Skill

## Responsibilities
- Architect secure enquiry submission and contact API routes.
- Implement server-side input validation (Zod schema validation).
- Enforce API security (rate limiting, honeypot spam protection, CORS, sanitized inputs).
- Persist structured lead records to MongoDB / secure database layer.
