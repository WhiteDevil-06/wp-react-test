# Responsive & Cross-Device Testing

## Viewport Grid
- Mobile Small: 360x640px
- Mobile Standard: 390x844px
- Tablet portrait: 768x1024px
- Desktop: 1440x900px

## Verification Targets
- Zero horizontal overflow (`overflow-x: hidden` verification).
- Mobile menu open/close interaction.
- Touch target sizing (minimum 44x44px).
- Font readability at mobile sizes.
