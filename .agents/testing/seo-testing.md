# SEO Verification Testing

- Inspect DOM for `<title>`, `<meta name="description">`, `<link rel="canonical">`, `<meta property="og:*">`.
- Verify presence of valid `<script type="application/ld+json">` tags.
- Run sitemap crawler simulation to ensure all route links exist and return 200 OK status code.
- Verify `robots.txt` accessibility.
